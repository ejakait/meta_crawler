#### Metadata to check and store

- Identity and location: name, bucket, id, generation, metageneration

- Size and checksums: size, crc32c, md5Hash

- Timestamps: timeCreated, updated, timeStorageClassUpdated, retentionExpirationTime, customTime

- HTTP / content: contentType, contentEncoding, contentLanguage, contentDisposition, cacheControl

- Storage / security: storageClass, kmsKeyName, retention/hold flags (event‑based hold, temporary hold), ACL/owners (if using ACLs instead of uniform bucket‑level access).
